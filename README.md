# 🎨 ColorCraft

**ColorCraft** es un videojuego web de estrategia de colores, jugable en modo local o multijugador en línea. Cuenta con inteligencia artificial para partidas en solitario, ofreciendo tres niveles de dificultad, y modo PvP usando WebSockets para juego en tiempo real entre dos personas.

## Características

- 🧠 **Inteligencia Artificial:** Juega contra la IA en tres niveles: Fácil, Medio y Difícil.
- 👥 **Multijugador Online:** Conéctate y juega en tiempo real con otra persona usando WebSockets.
- 🎮 **Modo Local:** Alterna turnos con un amigo en el mismo dispositivo.
